# equa.ai: тёмная фиолетовая тема

Рабочее приложение для антифрод-аналитика, сдержанный технический стиль.
Приоритет: читать цифры, сравнивать решения и проверять платежи.

## Рендер → код

Основа: два рендера Image to Code — обзор и проверка платежа.
Открытая строка метрик с разделителями; график 65% ширины, диаграмма 35%;
ниже журнал операций. В симуляторе форма и результат стоят рядом на широком экране.
Рендеры служат визуальными референсами; цифры и тексты в рабочем UI берутся из API.
Ошибочные даты, пользователи и вымышленные численные результаты из изображений не копируются.

## Токены

- Фон: #101014; боковое меню: #131218; панели: #18181e.
- Границы: #2b2935; основной текст: #f2effa; вторичный: #aba6b8.
- Акцент: #a78bfa; кнопка: #7250cc с белым текстом.
- Успех: #8ed6b0; проверка: #edc17b; блокировка: #f39da5.
- Скругления: панели 12px, поля и кнопки 8px, статусы 6px.
- Сетка: меню 224px, отступы 28–32px, промежутки 20–24px.
- Текст: Manrope / Segoe UI; основные подписи 14px, метаданные 12px.

## Применение скиллов

- Awesome Design: выбор подходящих инструментов, без повторной установки имеющихся скиллов.
- TasteSkill: иерархия, единая палитра, состояния форм; правила лендингов не применяются к таблицам.
- Humanizer: короткие функциональные заголовки вместо рекламных лозунгов.
- Image to Code + imagegen: рендеры созданы встроенным генератором, затем перенесены в HTML/CSS.
- Emil Kowalski: быстрый отклик кнопок, отсутствие постоянного движения, reduced motion.
- Web Design Guidelines: контраст, подписи, focus-visible, клавиатура, URL-состояние.
- Playwright CLI: проверка интерфейса после сборки.

## Анимация

Числовые компоненты Magic UI и один React Bits-компонент используются точечно.
Частые действия и клавиатурная навигация не ждут декоративных анимаций.
Не используются фоновые частицы, курсорные эффекты и бесконечные бегущие строки.

## Промпты рендеров

Встроенный imagegen. Ключевая инструкция финального изменения:
«Preserve the equa.ai dashboard/inspector hierarchy; use near-black graphite #101014,
panels #18181e, sidebar #131218, borders #2b2935, text #f2effa / #aba6b8,
violet #a78bfa accents. Keep Russian functional labels and large legible typography.
No neon glow, no marketing hero, no invented user identities.»
