## Изменения по Emil Design Engineering и Humanizer

| Before | After | Why |
| --- | --- | --- |
| Рекламные заголовки | «Обзор платежей», «Проверка платежа» | Быстрее найти нужное действие |
| Разрозненные зелёные оттенки | Общие токены тёмной фиолетовой темы | Соответствие выбранным рендерам |
| Unicode-символы меню | SVG с aria-hidden | Чёткие пиктограммы без лишнего чтения скринридером |
| Карточки метрик | Открытая строка с разделителями | Иерархия без лишних рамок |
| Резкая смена пояснения | FadeContent 180 мс без blur | Мягкое появление нового результата |
| Анимации при любом вводе | Статика для клавиатуры и reduced motion | Не задерживать повторяющиеся действия |
| Длинные дроби в NumberTicker | Локализованное форматирование начального значения | Нет переполнения и нечитабельных чисел |

## Web Design Guidelines

`frontend/index.html`: skip-link, подписи полей, native controls, ссылки разделов.
`frontend/app.js`: URL раздела, aria-current, пустые и ошибочные состояния,
экранирование строк, форматирование через Intl, сброс устаревшего результата.
`frontend/dark.css`: color-scheme, focus-visible, reduced motion, hover только
на указателях, локальные шрифты, адаптивные сетки.

Основные пары текста имеют контраст 5.62:1 или выше. Проверены основной и вторичный
текст, кнопка, три статуса. Это не полный аудит WCAG и не сертификация доступности.
Состояние раздела сохраняется в URL; настройки политики и фильтры пока живут в памяти вкладки.
