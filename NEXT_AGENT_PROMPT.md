Ты продолжаешь equa.ai для Overclock Hackathon 2026, трек FinTech.
Репозиторий: https://github.com/n0nam3e01/equa.ai, ветка main.

Сначала прочитай HANDOFF.md, TASKS.md, README.md и DESIGN.md в репозитории.
Проверь git status, текущий код и запуск; документы — снимок, код мог измениться.
Не создавай проект с нуля и не утверждай, что старые проверки автоматически
подтверждают новую версию.

Идея: система оценивает риск мошенничества, сравнивает ожидаемую стоимость
Approve / Challenge / Block и объясняет действие. Дополнительная ценность —
лаборатория настроек и проверка устойчивости к бизнес-допущениям.

Сейчас уже есть рабочий локальный MVP: Python/FastAPI, SQLite, 100 000 собственных
синтетических операций, Logistic Regression + калибровка, объяснения, пять экранов,
сравнение стратегий, демо-проверка и история. Supabase/PostgreSQL подготовлен,
но проекта и облачного подключения пока нет. Настоящая 2FA и банковская интеграция отсутствуют.
Тестовый генератор похож на модель, baseline не оптимизированы — экономию нельзя
выдавать за доказанный результат на реальных клиентах.

Сохраняй тёмную фиолетовую тему по design/overview-dark.png и design/inspector-dark.png.
Используй существующие Magic UI/React Bits точечно. Основной UI — HTML/CSS/JS с
React-островками; не мигрируй весь проект на другой стек без необходимости.
В коде нужны понятные русские комментарии и актуальная инструкция запуска.

Последний приоритет был закончить фронтенд, отложив развитие бэкенда. Теперь
выбери ограниченный следующий этап из TASKS.md согласно поручению команды.
Если конкретная задача не назначена, начни с проверки свежего запуска и состава
данных, кратко сформулируй следующий шаг. Не блокируй независимую работу из-за
отсутствия Supabase или датасета: готовь контракты/проверки, сохраняя явный demo-режим.

Ориентир дедлайна — 23 сентября 2026, 23:59 по Астане, но в документах есть
противоречия: команда должна подтвердить срок. Нужны рабочее демо, GitHub,
презентация до 12 слайдов, видео до 3 минут и опубликованный проект AI Startify
(Founder, OVRC, Incubator, модерация). Нельзя говорить, что эти пункты уже сделаны.

Действуй небольшими законченными шагами. Не трать время на длинные планы вместо
реализации. Сообщай, что изменил, чем проверил и что осталось. Секреты не размещай
