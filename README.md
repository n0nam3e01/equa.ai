# RallyGuard

RallyGuard — веб-прототип для BioTech-трека Overclock Hackathon 2026. Теннисист-любитель отмечает сон, энергию, усталость, стресс и дискомфорт, а приложение показывает личную динамику и отдельное объяснение каждого сигнала.

## Сценарий демо

1. Откройте [работающее демо](https://equa-ai.vercel.app/) и нажмите **Посмотреть демо**.
2. Откройте «Опрос» и измените сон, энергию, стресс или усталость.
3. Сохраните ответы: обзор покажет наблюдение и следующий шаг по каждому изменившемуся показателю.
4. В «Динамике» добавьте тренировку и посмотрите историю нагрузки.
5. В «Профиле» переключите сценарии «Усталость» и «Нужен разговор».
6. В «Тренере» сравните три вымышленных профиля.

Все стартовые профили и показатели вымышлены. Каждая браузерная сессия получает собственное пространство данных. Для защиты хакатона используйте только синтетические данные.

## Почему проект подходит BioTech

Кейс требует анализировать состояние и нагрузку атлета, показывать адаптивную рекомендацию и интерфейс для спортивного штаба. В MVP это реализовано как:

- чек-ин сна, энергии, стресса, усталости, дискомфорта и опциональных HRV/пульса;
- описательный индекс состояния с объяснением факторов и качеством истории;
- нагрузка `минуты × RPE` и история занятий;
- отдельные наблюдения и действия по сну, энергии, стрессу, усталости, дискомфорту и нагрузке;
- обзор тренера с возможностью сохранить решение;
- JSON-импорт показателей, экспорт и удаление демо-сессии;
- возможность подключить Groq для текстовых объяснений после настройки серверного ключа; в опубликованном демо AI-чат пока отключён.

Индекс в прототипе не является вероятностью травмы, медицинским допуском или диагностикой. При дискомфорте, мешающем движению, интерфейс предлагает обсудить состояние со специалистом. Основной разбор рассчитывается прозрачными правилами Python, поэтому работает без внешнего AI API.

## Запуск локально

Требуется Python 3.12+.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Откройте http://127.0.0.1:8000. Для обычного запуска используется SQLite в `data/rallyguard.db`. Скопируйте `.env.example` в `.env`, если нужно изменить режим хранения.

## Supabase

Выполните `supabase/migrations/202609220001_rallyguard.sql` в SQL Editor проекта Supabase. Затем добавьте локально или в Vercel Environment Variables:

```text
DATABASE_MODE=supabase
SUPABASE_URL=https://oitbqygljigiqrczqzdd.supabase.co
SUPABASE_SERVICE_ROLE_KEY=...
```

Ключ `service_role` хранится только на сервере. Браузер обращается только к нашему API. RLS включён, публичным ролям доступ к таблицам запрещён.

## AI

Для дальнейшего AI-слоя можно добавить `GROQ_API_KEY` и, при необходимости, `GROQ_MODEL` в `.env`. По умолчанию используется `openai/gpt-oss-20b`. Основной обзор не зависит от ключа. Не отправляйте во внешний API реальные медицинские сведения без явного согласия и проверки политики данных.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Проверки покрывают API, валидацию, изоляцию сессий, персональные сигналы, удаление/экспорт и статические файлы.

## Деплой

Репозиторий рассчитан на Vercel FastAPI: корень проекта — `.`, Output Directory оставьте пустым. `api/index.py` экспортирует FastAPI-приложение, а `vercel.json` направляет запросы к нему. Для постоянной истории на Vercel используйте Supabase; SQLite там временный.

Перед отправкой проекта на AI Startify команда должна добавить публичную ссылку на GitHub, live-ссылку или видео до 3 минут, питч до 12 слайдов и опубликовать карточку после AI Incubator с промокодом `OVRC`.

## Структура

| Путь | Назначение |
|---|---|
| `frontend/` | Адаптивная светлая спортивная вёрстка и клиентский сценарий |
| `backend/main.py` | FastAPI-маршруты, cookie-сессия и границы доступа |
| `backend/analytics.py` | Объяснимый описательный расчёт состояния |
| `backend/content.py` | Старый каталог уроков, не используемый в основном интерфейсе |
| `backend/storage.py` | SQLite/Supabase адаптер |
| `sql/` | Локальная SQL-схема |
| `supabase/migrations/` | Схема PostgreSQL для проекта Supabase |
| `tests/` | Серверные проверки |

Дизайн: молочный фон, лесной зелёный, теннисный лайм, Manrope, SVG-иконки и responsive layout для телефона и компьютера.
